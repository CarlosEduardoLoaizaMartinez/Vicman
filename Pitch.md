# Comprensión del desafío empresarial 20%:
SI hoy un cliente les envia un mensaje mostrando interes pero no compra en el momento, mañana tienes la forma de volver a buscarlo? o esa venta se perdio para siempre.
este es el caso de Agrovicman un negocio de produccion y procesamiento de cafe selecto de alta calidad, cosechado a 1200 msnm en santa Ana quillabamba, sus productos princiaples son el cafe de tasa geisha y sidra,
Las ventas que registra agrovigman son de 1500 a 2000 soles mensuales, y en temporadas altas, las ganancias asienden a 3500 soles, existen temporadas bajas donde al mes solo superan los 300 soles a menos, el problema detectado no es unicamente la captacion de nuevos clientes, agrovigman cuenta con una cartera de clientes, pero ese contacto se pierde en llamadas, mensajes de voz, whatsapp y recuerdos. esto dificulta saber quien compro quien mostro interes y a quien deberiamos volver a contactar, para convertir las compras ocacionales en relacion dudareras.

#Usa la tecnología de forma original y precisa para este problema: 
Para resolver este problema presentamos un sistema de gestion comercial inteligente integrada con IA para registrar clientes, responder consultas y facilitar el registro/seguimiento de las oportunidades de ventas. la solucion cuenta con 3 funcionalidades clave adaptadas a las necesidades reales de agroviman, para una mayor usabilidad el sistema cuenta con el registro inteligente por voz, ejemplo durante una feria, la administradora podra enviar un audio inidcando los datos del cliente, cuanto pago, el numero de telefono,cuanto pago que compro, y el modelo de ia procesara el audio y lo guardara la informacion en una base de datos, sin registrarlo manualmente.
 la segunda funcionalidad es la atencion inteligente, agrovicman mas alla de vender cafe es un centro de aprendizaje donde los clientes consultan sobre el cultivo, preparacion de cafe, este sistema inteligente ayuda a enviar informacion real de todo el proceso de preparacion y responde automaticamente.
